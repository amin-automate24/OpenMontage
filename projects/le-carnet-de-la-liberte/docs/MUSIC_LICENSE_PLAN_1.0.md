# MUSIC LICENSE VERIFICATION PLAN 1.0 (D12) — préparation, **0 dépense**

**État :** aucune piste n'est retenue, donc **aucune licence n'est « vérifiée » à ce jour** (je ne l'affirme pas). `music_library/` est vide.

## Procédure (gratuite)
1. Vous (ou moi, sur votre demande) présélectionnez 3 pistes dans une source à licence claire : YouTube Audio Library, Jamendo, Free Music Archive, Pixabay Music ou une piste que vous possédez.
2. Pour chaque piste, on archive dans `approvals/licenses/` : capture ou texte de la licence, URL, auteur, date de consultation, type (CC0 / CC-BY / licence plateforme) et exigences (attribution, usage commercial, usage éducatif, diffusion en ligne).
3. **Critères d'acceptation :** usage éducatif et diffusion en ligne autorisés ; attribution possible dans le générique ; pas de Content ID/réclamation connu ; aucune imitation d'un hymne ou d'une œuvre existante.
4. Contrôle de durée : thème de ~60–90 s en boucle ou 3 pistes courtes (voir repères M1–M8 dans `docs/SOUND_MUSIC_AND_RESOLVE_PLAN_1.0.md`).
5. Dépôt dans `music_library/` uniquement après vérification ; journal dans le registre d'approbations.
